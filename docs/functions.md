# Описание функций

Все функции лежат в пакете `numtheory` и принимают целые числа. Если передать не целое число (например, `2.5`, `"7"` или `True`), функция выбросит `TypeError`. Это относится ко всем функциям, поэтому ниже в разделе «Исключения» указан только `ValueError`.

Функции импортируются из своих модулей:

```python
from numtheory.primes import is_prime, primes_up_to, factorize
from numtheory.divisors import gcd, lcm, divisors, is_perfect
from numtheory.sequences import fibonacci, fibonacci_list, factorial
```

## Содержание

1. Модуль `primes`: [is_prime](#is_prime), [primes_up_to](#primes_up_to), [factorize](#factorize)
2. Модуль `divisors`: [gcd](#gcd), [lcm](#lcm), [divisors](#divisors), [is_perfect](#is_perfect)

## Модуль primes

### is_prime

```python
is_prime(number: int) -> bool
```

Проверяет, является ли число простым. Простыми считаются только натуральные числа больше 1, поэтому для 0, 1 и отрицательных чисел функция возвращает `False`.

**Параметры:**

- `number` (*int*): проверяемое число

**Возвращает:** `True`, если число простое, иначе `False`.

**Пример:**

```python
is_prime(17)   # True
is_prime(15)   # False
is_prime(-7)   # False
```

### primes_up_to

```python
primes_up_to(number: int) -> list[int]
```

Возвращает все простые числа от 2 до `number` включительно. Работает решетом Эратосфена. Если `number` меньше 2, список пустой.

**Параметры:**

- `number` (*int*): верхняя граница поиска, включительно

**Возвращает:** список простых чисел по возрастанию.

**Пример:**

```python
primes_up_to(20)   # [2, 3, 5, 7, 11, 13, 17, 19]
primes_up_to(1)    # []
```

### factorize

```python
factorize(number: int) -> list[int]
```

Раскладывает число на простые множители. У отрицательного числа первым множителем идёт `-1`, у единицы множителей нет.

**Параметры:**

- `number` (*int*): раскладываемое число, не равное 0

**Возвращает:** список простых множителей по возрастанию с повторениями. Их произведение равно `number`.

**Исключения:** `ValueError`, если `number` равен 0.

**Пример:**

```python
factorize(60)    # [2, 2, 3, 5]
factorize(-12)   # [-1, 2, 2, 3]
factorize(1)     # []
```

## Модуль divisors

### gcd

```python
gcd(number1: int, number2: int) -> int
```

Находит наибольший общий делитель (НОД) алгоритмом Евклида. Знаки чисел на результат не влияют. Если одно из чисел равно 0, результат равен модулю другого.

**Параметры:**

- `number1` (*int*): первое число
- `number2` (*int*): второе число

**Возвращает:** НОД, всегда неотрицательный.

**Пример:**

```python
gcd(48, 18)    # 6
gcd(-12, 18)   # 6
gcd(7, 0)      # 7
```

### lcm

```python
lcm(number1: int, number2: int) -> int
```

Находит наименьшее общее кратное (НОК) по формуле `abs(a * b) // gcd(a, b)`. Если одно из чисел равно 0, результат равен 0.

**Параметры:**

- `number1` (*int*): первое число
- `number2` (*int*): второе число

**Возвращает:** НОК, всегда неотрицательное.

**Пример:**

```python
lcm(4, 6)    # 12
lcm(-4, 6)   # 12
lcm(5, 0)    # 0
```

### divisors

```python
divisors(number: int) -> list[int]
```

Возвращает все натуральные делители числа. У отрицательного числа делители те же, что у его модуля.

**Параметры:**

- `number` (*int*): число, не равное 0

**Возвращает:** список делителей по возрастанию, от 1 до модуля числа.

**Исключения:** `ValueError`, если `number` равен 0: у нуля бесконечно много делителей.

**Пример:**

```python
divisors(36)   # [1, 2, 3, 4, 6, 9, 12, 18, 36]
divisors(-6)   # [1, 2, 3, 6]
```

### is_perfect

```python
is_perfect(number: int) -> bool
```

Проверяет, является ли число совершенным, то есть равным сумме своих делителей без самого себя. Например, 6 = 1 + 2 + 3. Для 0, 1 и отрицательных чисел возвращает `False`.

**Параметры:**

- `number` (*int*): проверяемое число

**Возвращает:** `True`, если число совершенное, иначе `False`.

**Пример:**

```python
is_perfect(28)   # True
is_perfect(12)   # False
```

## Модуль sequences

### fibonacci

```python
fibonacci(number: int) -> int
```

Возвращает число Фибоначчи с номером `number`. Нумерация с нуля: F(0) = 0, F(1) = 1. Для отрицательных номеров работает формула F(-n) = (-1)^(n+1) · F(n).

**Параметры:**

- `number` (*int*): номер в последовательности, любое целое число

**Возвращает:** число Фибоначчи F(number).

**Пример:**

```python
fibonacci(10)   # 55
fibonacci(0)    # 0
fibonacci(-4)   # -3
```

### fibonacci_list

```python
fibonacci_list(number: int) -> list[int]
```

Возвращает первые `number` чисел Фибоначчи, начиная с F(0) = 0.

**Параметры:**

- `number` (*int*): сколько чисел вернуть, не меньше 0

**Возвращает:** список из `number` чисел.

**Исключения:** `ValueError`, если `number` отрицательный.

**Пример:**

```python
fibonacci_list(8)   # [0, 1, 1, 2, 3, 5, 8, 13]
fibonacci_list(0)   # []
```

### factorial

```python
factorial(number: int) -> int
```

Вычисляет факториал n! = 1 · 2 · … · n. По определению 0! = 1.

**Параметры:**

- `number` (*int*): неотрицательное число

**Возвращает:** факториал числа.

**Исключения:** `ValueError`, если `number` отрицательный.

**Пример:**

```python
factorial(5)   # 120
factorial(0)   # 1
```
