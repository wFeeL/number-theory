# Описание функций

Все функции лежат в пакете `numtheory` и принимают целые числа. Если передать не целое число (например, `2.5`, `"7"` или `True`), функция выбросит `TypeError`. Функция `crt` принимает также списки целых чисел: `TypeError` будет, если аргумент не список и не кортеж или если какой-то его элемент не целое число (в тексте ошибки указан номер элемента, например `remainders[1]`). Проверку выполняет декоратор `ints_only` по аннотациям функций. Это относится ко всем функциям, поэтому ниже в разделе «Исключения» указан только `ValueError`.

Функции импортируются из своих модулей:

```python
from numtheory.primes import is_prime, primes_up_to, factorize
from numtheory.divisors import gcd, lcm, divisors, is_perfect, euler_phi
from numtheory.modular import extended_gcd, mod_inverse, solve_diophantine, crt
from numtheory.sequences import fibonacci, fibonacci_list, factorial
```

## Модуль primes

### is_prime

```python
is_prime(number: int) -> bool
```

Проверяет, является ли число простым. Простыми считаются только натуральные числа больше 1, поэтому для 0, 1 и отрицательных чисел функция возвращает `False`.

**Параметры:**

- `number` (*int*): проверяемое число

**Возвращает:** `True`, если число простое, иначе `False`.

**Пример:**

```python
is_prime(17)   # True
is_prime(15)   # False
is_prime(-7)   # False
```

### primes_up_to

```python
primes_up_to(number: int) -> list[int]
```

Возвращает все простые числа от 2 до `number` включительно. Работает решетом Эратосфена. Если `number` меньше 2, список пустой.

**Параметры:**

- `number` (*int*): верхняя граница поиска, включительно

**Возвращает:** список простых чисел по возрастанию.

**Пример:**

```python
primes_up_to(20)   # [2, 3, 5, 7, 11, 13, 17, 19]
primes_up_to(1)    # []
```

### factorize

```python
factorize(number: int) -> list[int]
```

Раскладывает число на простые множители. У отрицательного числа первым множителем идёт `-1`, у единицы множителей нет.

**Параметры:**

- `number` (*int*): раскладываемое число, не равное 0

**Возвращает:** список простых множителей по возрастанию с повторениями. Их произведение равно `number`.

**Исключения:** `ValueError`, если `number` равен 0.

**Пример:**

```python
factorize(60)    # [2, 2, 3, 5]
factorize(-12)   # [-1, 2, 2, 3]
factorize(1)     # []
```

## Модуль divisors

### gcd

```python
gcd(number1: int, number2: int) -> int
```

Находит наибольший общий делитель (НОД) алгоритмом Евклида. Знаки чисел на результат не влияют. Если одно из чисел равно 0, результат равен модулю другого.

**Параметры:**

- `number1` (*int*): первое число
- `number2` (*int*): второе число

**Возвращает:** НОД, всегда неотрицательный.

**Пример:**

```python
gcd(48, 18)    # 6
gcd(-12, 18)   # 6
gcd(7, 0)      # 7
```

### lcm

```python
lcm(number1: int, number2: int) -> int
```

Находит наименьшее общее кратное (НОК) по формуле `abs(a * b) // gcd(a, b)`. Если одно из чисел равно 0, результат равен 0.

**Параметры:**

- `number1` (*int*): первое число
- `number2` (*int*): второе число

**Возвращает:** НОК, всегда неотрицательное.

**Пример:**

```python
lcm(4, 6)    # 12
lcm(-4, 6)   # 12
lcm(5, 0)    # 0
```

### divisors

```python
divisors(number: int) -> list[int]
```

Возвращает все натуральные делители числа. У отрицательного числа делители те же, что у его модуля.

**Параметры:**

- `number` (*int*): число, не равное 0

**Возвращает:** список делителей по возрастанию, от 1 до модуля числа.

**Исключения:** `ValueError`, если `number` равен 0: у нуля бесконечно много делителей.

**Пример:**

```python
divisors(36)   # [1, 2, 3, 4, 6, 9, 12, 18, 36]
divisors(-6)   # [1, 2, 3, 6]
```

### is_perfect

```python
is_perfect(number: int) -> bool
```

Проверяет, является ли число совершенным, то есть равным сумме своих делителей без самого себя. Например, 6 = 1 + 2 + 3. Для 0, 1 и отрицательных чисел возвращает `False`.

**Параметры:**

- `number` (*int*): проверяемое число

**Возвращает:** `True`, если число совершенное, иначе `False`.

**Пример:**

```python
is_perfect(28)   # True
is_perfect(12)   # False
```

### euler_phi

```python
euler_phi(number: int) -> int
```

Вычисляет функцию Эйлера: количество чисел от 1 до `number`, взаимно простых с `number`. Раскладывает число на простые множители функцией `factorize` и для каждого различного простого `p` умножает результат на `(1 - 1/p)`. Для единицы возвращает 1.

**Параметры:**

- `number` (*int*): натуральное число

**Возвращает:** количество чисел от 1 до `number`, взаимно простых с `number`.

**Исключения:** `ValueError`, если `number` меньше 1: функция Эйлера определена только для натуральных чисел.

**Пример:**

```python
euler_phi(36)   # 12
euler_phi(13)   # 12
euler_phi(1)    # 1
```

## Модуль modular

### extended_gcd

```python
extended_gcd(a: int, b: int) -> tuple[int, int, int]
```

Расширенный алгоритм Евклида. Возвращает тройку `(g, x, y)`, для которой `a * x + b * y == g`, где `g` это НОД чисел `a` и `b`, всегда неотрицательный. Работает с отрицательными числами и нулями. Если один из аргументов равен 0, коэффициент при этом нулевом аргументе равен 0, а при другом равен 1 или -1. Для пары `(0, 0)` возвращает `(0, 0, 0)`.

**Параметры:**

- `a` (*int*): первое число
- `b` (*int*): второе число

**Возвращает:** кортеж `(g, x, y)`, где `g = НОД(a, b)` и `a * x + b * y = g`.

**Пример:**

```python
extended_gcd(240, 46)   # (2, -9, 47), потому что 240 * (-9) + 46 * 47 = 2
extended_gcd(-12, 18)   # (6, 1, 1)
extended_gcd(5, 0)      # (5, 1, 0)
extended_gcd(0, 0)      # (0, 0, 0)
```

### mod_inverse

```python
mod_inverse(a: int, m: int) -> int
```

Находит число `x`, обратное к `a` по модулю `m`, то есть такое, что `a * x % m == 1`. Результат лежит в диапазоне от 0 до `m - 1`. Обратное существует, только если `a` и `m` взаимно просты. Для отрицательного `a` используется его класс вычетов по модулю `m`. При `m = 1` любые два числа сравнимы, поэтому обратным считается 0, как у встроенного `pow(a, -1, 1)`.

**Параметры:**

- `a` (*int*): число, для которого ищется обратное
- `m` (*int*): модуль, натуральное число

**Возвращает:** обратное к `a` по модулю `m`.

**Исключения:** `ValueError`, если `m` меньше 1 или `НОД(a, m)` не равен 1.

**Пример:**

```python
mod_inverse(3, 7)    # 5, потому что 3 * 5 = 15 = 2 * 7 + 1
mod_inverse(-3, 7)   # 2
mod_inverse(5, 1)    # 0
mod_inverse(4, 8)    # ValueError: у 4 нет обратного по модулю 8
```

### solve_diophantine

```python
solve_diophantine(a: int, b: int, c: int) -> tuple[int, int, int, int]
```

Решает уравнение `a * x + b * y = c` в целых числах. Возвращает общее решение `(x0, y0, dx, dy)`: все решения имеют вид `x = x0 + dx * t`, `y = y0 + dy * t` для целого `t`, других нет.

Нормализация: при `b`, не равном 0, шаг `dx = |b| / НОД(a, b)` положителен, а `x0` наименьшее неотрицательное, то есть `0 <= x0 < dx`. Если `b = 0`, а `a` не равно 0, то `x` однозначно равен `c / a`, а `y` свободен: результат `(c / a, 0, 0, 1)`. Если `a = 0`, а `b` не равно 0, то `y` однозначно равен `c / b`, а свободен `x`: результат `(0, c / b, 1, 0)`.

**Параметры:**

- `a` (*int*): коэффициент при `x`
- `b` (*int*): коэффициент при `y`
- `c` (*int*): правая часть уравнения

**Возвращает:** кортеж `(x0, y0, dx, dy)`.

**Исключения:** `ValueError`, если `c` не делится на `НОД(a, b)` (целых решений нет) и если `a = b = 0` (при `c`, не равном 0, решений нет, при `c = 0` подходит любая пара и параметризации нет).

**Пример:**

```python
solve_diophantine(3, 5, 1)    # (2, -1, 5, -3): x = 2 + 5t, y = -1 - 3t
solve_diophantine(6, 9, 15)   # (1, 1, 3, -2)
solve_diophantine(4, 0, 8)    # (2, 0, 0, 1)
solve_diophantine(0, 4, 8)    # (0, 2, 1, 0)
solve_diophantine(6, 9, 7)    # ValueError: 7 не делится на НОД(6, 9) = 3
```

### crt

```python
crt(remainders: list[int], moduli: list[int]) -> tuple[int, int]
```

Решает систему сравнений `x = r_i (mod m_i)` по китайской теореме об остатках. Модули не обязаны быть попарно взаимно простыми: система совместна, только если для каждой пары `r_i - r_j` делится на `НОД(m_i, m_j)`. Результат `(x, M)` описывает все решения: это числа `x + M * t` для целого `t`, где `M` равно НОК всех модулей, а `0 <= x < M`. Отрицательные остатки допустимы. Вместо списков можно передать кортежи.

**Параметры:**

- `remainders` (*list[int]*): остатки `r_i`
- `moduli` (*list[int]*): модули `m_i`, натуральные числа, по одному на каждый остаток

**Возвращает:** пару `(x, M)`.

**Исключения:** `ValueError`, если длины списков разные, списки пустые, какой-либо модуль меньше 1 или система несовместна.

**Пример:**

```python
crt([2, 3, 2], [3, 5, 7])   # (23, 105)
crt([1, 3], [4, 6])         # (9, 12): модули не взаимно просты, но система совместна
crt([-1], [7])              # (6, 7)
crt([1, 2], [4, 6])         # ValueError: система несовместна
```

## Модуль sequences

### fibonacci

```python
fibonacci(number: int) -> int
```

Возвращает число Фибоначчи с номером `number`. Нумерация с нуля: F(0) = 0, F(1) = 1. Для отрицательных номеров работает формула F(-n) = (-1)^(n+1) · F(n).

**Параметры:**

- `number` (*int*): номер в последовательности, любое целое число

**Возвращает:** число Фибоначчи F(number).

**Пример:**

```python
fibonacci(10)   # 55
fibonacci(0)    # 0
fibonacci(-4)   # -3
```

### fibonacci_list

```python
fibonacci_list(number: int) -> list[int]
```

Возвращает первые `number` чисел Фибоначчи, начиная с F(0) = 0.

**Параметры:**

- `number` (*int*): сколько чисел вернуть, не меньше 0

**Возвращает:** список из `number` чисел.

**Исключения:** `ValueError`, если `number` отрицательный.

**Пример:**

```python
fibonacci_list(8)   # [0, 1, 1, 2, 3, 5, 8, 13]
fibonacci_list(0)   # []
```

### factorial

```python
factorial(number: int) -> int
```

Вычисляет факториал n! = 1 · 2 · … · n. По определению 0! = 1.

**Параметры:**

- `number` (*int*): неотрицательное число

**Возвращает:** факториал числа.

**Исключения:** `ValueError`, если `number` отрицательный.

**Пример:**

```python
factorial(5)   # 120
factorial(0)   # 1
```
